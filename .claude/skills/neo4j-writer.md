# Mindrian-Team-Neo4j-Writer

Safely write to the Mindrian Neo4j knowledge graph with schema governance and pre-flight checks.

Read the full skill guide: `skills/neo4j-graph-writer/SKILL.md`

## Usage

Add nodes, relationships, or structured knowledge to the graph.

## Pre-Flight Checklist

1. **WHAT** are you adding? (Node/Relationship, Label, Properties)
2. **WHY** does it belong? (Query path, Layer, Larry benefit)
3. **HOW** safely? (MERGE not CREATE, Batch ≤200, Rollback plan)
