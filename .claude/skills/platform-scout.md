# Platform Scout

Research and evaluate alternative frontend platforms for Mindrian.

Read the full skill guide: `skills/platform-scout/SKILL.md`

## Quick Start

Ask about:
- "Research [platform name] as a Mindrian frontend"
- "Compare Tari vs KUSE vs Chainlit"
- "What new MCP-compatible chat UIs exist?"
- "Evaluate [platform] against our criteria"

## Evaluation Criteria (ranked)
1. MCP Support (native tool consumption)
2. BYOK (Bring Your Own Key)
3. Rebrandable (deploy as "Mindrian")
4. Chat Interface + File Upload
5. Skills/Plugins + Custom Components
