## Available Skills

| Skill | Command | Purpose |
|-------|---------|---------|
| Swarm | `/swarm` | Multi-agent coordination |
| Commit Expert | `/commit-expert` | Change tracking |
| QA Consultant | `/qa` | Testing & quality |
| R&D Consultant | `/rnd` | Architecture decisions |
| Stack | `/stack` | Technical stack |

## Quick Start

```
/swarm What do agents think about X?
/commit-expert What changed recently?
/qa What should we test?
```
