# Conversation Reviewer

Extract actionable development briefs from team meetings and testing sessions.

Read the full skill guide: `skills/conversation-reviewer/SKILL.md`

## Quick Start

Paste any of these and ask for a review:
- Meeting transcript
- Testing feedback email
- Chat session log
- User complaints / feature requests

## What You Get

- **P0/P1/P2 bug reports** with files to inspect
- **UX friction points** with fix recommendations
- **Protected features** (things that work well — don't touch!)
- **Consensus detection** (2+ testers agree = validated)
- **Testing assignments** with ownership
